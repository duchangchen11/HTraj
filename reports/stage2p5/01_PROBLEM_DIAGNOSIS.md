# 问题诊断：代码事实、实验现象与原因假设

日期：2026-10-14。原Stage2数据和权重保留；本阶段不把5epoch smoke直接与新30epoch模型排序。以下第一轮结论来自所有候选重新训练的相同30epoch预算。第二轮三种子与推理干预结果在最终总报告中汇合。

## 十项问题逐项核查

| 问题 | 可直接确认/已测事实 | 原因解释边界 |
|---|---|---|
| ego是否完整保留 | A0有交互时用mix MLP，无恒等主路径；无邻居返回自身ego | 不是ego变量丢失；不能从结构直接断言信息全毁 |
| 融合MLP是否改变ego | A0的decoder输入为重映射；R/RN显式ego+delta | 性能因果需同预算四版本比较 |
| 状态尺度增长 | Stage2三阶18.25；本轮A0末轮约18.60，R末轮约102.92 | 大范数不必然导致误差；N控制读出而非carry |
| 投影梯度是否正常 | 逐epoch保存q投影和gate梯度；A0末轮q1/q2/q3约0.0709/0.0546/0.0122且有限 | 三阶没有完全断梯度；小梯度不等于无贡献 |
| 是否依赖二阶 | A0末轮beta约0.500/0.412/0.053，R约0.834/0.106/0.026 | 早期0.752二阶占优不是固定现象 |
| 三阶为何权重低 | 三阶幅度大且beta小；R gate末轮均值约0.100且无低于1e-3的active值 | 可能尺度、重复信息、损失偏好；不能仅由beta判无用 |
| 训练预算是否一致 | 第一轮10模型均30epoch/960步，数据、种子、loss/head一致 | 参数和实测耗时不等；扩宽control另注明 |
| 收敛差异 | 普通社会网络5epoch仍慢，继续训练明显追近PedBase | 5epoch不足以评价最终能力 |
| 增加轮次能否改变结论 | 差距大幅缩小，30epoch第一轮仍未超过PedBase | 本轮最多30，不无限追加以追求好结果 |
| 密度差异 | 高密度Dyn-RN有小幅改善，TOHI仍未稳定改善；无邻居组多为短历史 | 需按预设组和可观测历史构成解释，不把无链当因果标签 |

## 概念上最容易误判的两点

小beta不等于小影响：较大状态范数乘较小权重仍可产生明显pool，而且gate、score与decoder是非线性的。三阶作用最终按消息删除/阶cap的反事实测量，但它只是固定checkpoint的敏感性，不是独立重训练的高阶贡献。

无邻居/无链组不是干净的“没有社会关系”群体。41个无邻居可评价目标中65.85%只有一个历史点，平均2.54个点；高邻居组平均7.61点。因信息量和进入时间不同，这些组的误差不能反推出社会传播有效。分组规则未改变，描述性构成已存CSV。

## 目前可说与不可说

可以说：A0有额外重映射，原5epoch对照未充分训练，raw高阶状态尺度增长真实存在，残差路径实际参与计算且有梯度。不能说：这些已被证明是全部弱于PedBase的原因，或归一化已证明性能改善，或二阶/三阶真实社会因果强度已识别。阶段最终判断以稳定性和干预表为准。
