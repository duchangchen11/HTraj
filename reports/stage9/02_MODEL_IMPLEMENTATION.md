# 模型实现与来源

独立实现：`scripts/stage9/common.py`，继承并调用冻结的原`ResonanceLayer`，遵守GPL-3.0及`LICENSE_NOTICE.md`。所有Transformer、运动编码、线性预测、SelfBias/ReBias及解码直接使用原代码。A原聚合未改。

设h_j∈R64为原运动谱特征，g_j=ce([d_j,θ_j])∈R64为原位置编码器用于单邻居的位置特征；θ沿原实现atan2(x,y)，8分区。R⁰_p∈R128由原代码返回：先分别均值，再对均值位置编码，分母原n+0.0001。原论文位置编码顺序与源码的差别按源码固定。

B：Rᴮ_p=R⁰_p+mean_j W₂ tanh(W₁[g_j,h_j])。W₁:128→32，W₂:32→128，无bias，新增8,192参数。空分区残差为0；分区均值使用真实有效计数（至少1），不修改R⁰原分母。

C：U,V:64→32，W:32→128，均无bias；u=Ug，v=Vh。

Rᶜ_p=R⁰_p+W[mean(u⊙v)−mean(u)⊙mean(v)]。

这是完整中心化交叉矩M=mean((g−ḡ)⊗(h−h̄))的32个双线性投影diag(U M Vᵀ)，非显式4096维矩展开。计数≤1时交叉项定义为0。三矩阵共8,192参数，与B完全相同。未增加门控/注意力/解码器/新loss。

A总参数3,149,192；B/C均3,157,384，比A多0.2601%。BvsA仍有容量与函数类混杂；CvsB排除参数数量差别，不等于排除归纳偏置、优化路径及函数类差别。C的单邻居交叉项为零也是机制差异，不能隐藏。

共同新增聚合复杂度O(B·N·64·32+B·8·N·32)，原Transformer成本保留；存储额外O(BN·128)。B需要非线性联合编码，线性拼接均值仍无法绑定。预检发现ReLU在固定见证落于同一线性区，训练/验证精度曝光前改为Tanh；保留失败记录。此结构验证不构成预测优势。

原始和新增参数在57邻居人工batch均有有限梯度；C单邻居无交叉信息、其新增梯度为零符合定义。原模型也有条件性参数路径，不将所有名义参数自动称为每样本有效容量。仅实际固定预算结果决定是否继续。
