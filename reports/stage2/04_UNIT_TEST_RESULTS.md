## 覆盖与独立判据

| 用户要求 | 实际测试 |
|---|---|
| 单/多人、padding | 四模型分别验证输出形状、masked NaN 不污染、padding 输出零 |
| 行人置换等变 | 四模型及 top-k 边界同分不按下标选择 |
| 无邻居 | 与加载相同 encoder/decoder 权重的 PedBase 精确比较 |
| 一阶 | 人工图与单位投影、固定 gamma，验证数值1 |
| 二阶正序 | A→B@1，B→C@3；C 二阶0.5（等待一帧衰减） |
| 二阶逆序 | 交换事件时标，C 二阶拓扑无效且数值0 |
| 同帧读写隔离 | 同帧 A→B→C 不生成二阶 |
| 三阶 | A→B@1→C@2→D@3，三阶单位消息为1 |
| 等待不增阶 | 一条边后6步等待，只有一阶，数值0.5^6 |
| 拓扑与数值区分 | W=0 时数值全零，但合法二阶 support 仍 true |
| 前缀不变性 | 改后续观察：ego、各阶/动态状态和图权重前缀不变；梯度到后续为0 |
| 未来 GT 隔离 | 模型拒绝 future 参数；数据未来-only 人及改未来坐标不改变输入集合 |
| 正常反向传播 | 四模型 loss、存在的梯度均有限 |
| 数值稳定 | 重合点、大幅坐标、空邻域；有效 NaN 明确拒绝 |
| 场景/调用隔离 | batched 与独立场景一致；不同调用不保留隐藏状态 |
| 缺失和时间 | 断轨重现 reset，实际秒数差分，长 gap reset |
| 数据协议 | 五折时域支持无交集、测试场景排除、raw hash 防更改、禁止覆盖 manifest |
| 评价 | 部分未来 mask 和最后时间点 FDE 分母手算对照 |
| 统计 oracle | 合成正逆序、carry 不重复计数、返回原人和中介失效 |

测试使用人工图的显式 support 与固定正投影，不依赖自然轨迹可视化。GPU 的真实训练/反向传播验证单独记录在 smoke 报告。本测试并不能证明物理因果、预测有效性或全部数据质量。
