## 2. 结构正确性与合成任务

| 检查 | 操作 | 通过条件 |
|---|---|---|
| 顺序支持 | 人工图 $a\to b@2,b\to c@4$；交换时标 | 二阶支持正序存在、逆序不存在 |
| 阶数分离 | 只有一条社会事件；插入等待 | 二阶/三阶保持无效，等待不增阶 |
| 同帧约束 | 同帧 $a\to b,b\to c$ | 严格候选拒绝二阶 |
| 前缀不变性 | 改动 $t$ 之后的观察位置 | 时间 $t$ 内部状态不变，梯度支持为零 |
| 场景和 ID | padding、置换、两 scene 混 batch、序列重置 | mask 无污染，置换等变，状态不跨 scene/序列 |
| DAG 有效性 | 无前驱、超 $\Delta$、断轨中介 | B 的不存在阶数返回零、不 NaN |

结构支持检查用固定正权重或 symbolic/Boolean 路径 oracle，避免学习参数恰为零导致误判。再建立规则驱动避让/反应延迟合成任务，保留生成规则，不称其为真实人群机制。合成图时标置换保持节点特征与边集合，专测传播顺序；自然轨迹时序打乱会改变速度等因素，仅作辅助鲁棒性分析。

## 3. 公平对照与消融矩阵

共用 ego 和 decoder 的内部对照：ego-only；一阶同帧 GNN；同帧多阶邻接幂与融合；动态图 GNN+GRU；A；B。外部 HighGraph/UniEdge 官方结果作为来源表，另做统一协议可复现版本并明确区别。HoGAT 获取全文后决定是否可复现；没有实现前不承诺已纳入训练。

| 目的 | 对照/消融 | 固定条件 |
|---|---|---|
| 高阶必要性 | $H=1,2,3$，无阶通道 GNN，增宽 GNN | 近似等参数、相同 decoder |
| 时间约束必要性 | 相同候选边预算的 ordered/unordered、forward/bidirectional | 相同特征和关系打分 |
| A 机制 | 无 carry、固定 decay、learned decay、跨阶共享/独立 | 不引入其它新模块 |
| B 机制 | 共享端点 line graph；仅时间；端点方向+时间；完整 gate | 相同事件 token 与边预算 |
| 稀疏/几何收益 | 距离图、运动风险图、随机等边数图 | 同传播结构 |
| 邻居和延迟 | $k=4,8,12$；$\Delta=1,2,4$；等待/缺失 | 验证集选择，不测试调参 |
| 容量归因 | 扩宽 baseline 与参数匹配变体 | 参数和 FLOPs 都记录 |
| 预测器归因 | 确定性共享 head；随后统一概率 head | 不混 K=1 和 K=20 |

受方向/时间 mask 的 UniEdge 变体需在其论文设计上明确改动；不能使用公开 `K=1` 代码作为“完整 E2E 已运行”对照。时间路径原型另与 TGN 类节点记忆和 DBGNN 类路径状态概念对照；若没有完成原方法复现，报告称简化对照，不称官方模型。

## 4. 指标与统计

$$\mathrm{ADE}=\frac1{NT_p}\sum_{i,t}\|\widehat y_i^t-y_i^t\|_2,\qquad
\mathrm{FDE}=\frac1N\sum_i\|\widehat y_i^{T_p}-y_i^{T_p}\|_2.$$

概率评价先对每条完整预测计算 ADE/FDE 再取样本最小，不能逐时刻拼选不同样本；报告 minADE20、minFDE20 是分别取最小还是采用同一选中轨迹，评估器必须注明。确定性指标单独列出。将 joint scene sample 与每人独立选样本明确分开。

碰撞率：每个联合场景样本中，任意两人同时距离小于预注册阈值（如米制 0.2m）的未来帧比例及发生任一碰撞的样本比例；排除自身和 invalid，必要时做时间线段插值。SDD 须有米标定才用米阈值，否则报告像素阈值。不能用各人独立 oracle-best 拼接来主张联合安全性。阈值是诊断规格，不是统一的人体物理真值。

计划三种子（17、42、2026），五场景均报告、场景宏平均与样本加权平均分开。报告均值和标准差；场景/连续片段聚类 bootstrap 置信区间，避免将高度重叠窗口当独立样本。三种子仅提供初步稳定性，不足以保证普遍显著。
